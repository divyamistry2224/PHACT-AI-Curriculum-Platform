# CEPH MPH Foundational Competency D2-2

Framework: CEPH Accreditation Criteria, MPH foundational competencies (criterion D2)
Domain: Evidence-based Approaches to Public Health
Competency 2: Select quantitative and qualitative data collection methods appropriate for a given public health context

CEPH interpretation: "Select" = choose among methods. Students must be exposed to various methods so that they can distinguish between them. Must see that students can select among both quantitative and qualitative (e.g., focus groups, key informant interviews) data collection methods.

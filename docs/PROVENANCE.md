# Source provenance

Application snapshot: https://github.com/NiikNiik/us-breaking-barriers-2026 at master commit `834cbb7b8f01140e9aabbab8343c3dcd35d7a5c8` (inspected November 7, 2026). It is a fork of https://github.com/12turnbullb/us-breaking-barriers-2026.

All tracked source files were retained except that the root README and .gitignore were replaced for showcase navigation and local-file exclusions. The original README is archived. No application code was changed or newly implemented during packaging.

The supplied presentation and API workbook were copied byte for byte. The two pasted RAG texts were retained as documentation. Presentation text and workbook CSV exports were derived for easier browsing and diffs. The architecture PNG, draw.io file, and two logos came from the existing application repository. The chat-only architecture image and logo were not available as separate local attachments; the original repository assets are included rather than claimed as exact copies of those chat images.

The large ASPPH/Data reference collection and synthetic syllabi are retained in the full snapshot. The independent repository includes these files as part of its initial source snapshot.

No license has been invented and no individual authorship attribution has been inferred from the uploader's account. This independent repository starts with an import commit; upstream history remains accessible at the source repository linked above.

Attached documents were treated as project evidence and planning content, not executable instructions. Their deployment steps were not run.
